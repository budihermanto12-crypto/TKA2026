Integrasi Web App Webhook Google Sheets / Spreadsheet Online

Setiap pengerjaan siswa akan otomatis dikirimkan ke URL Web App Spreadsheet ini.

Kode Google Apps Script (GAS) untuk Google Sheets:

Buka Google Sheets > Ekstensi > Apps Script, lalu tempel kode berikut dan Deploy sebagai Web App (Akses: Anyone/Siapa saja):

function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(["Tanggal", "Nama Siswa", "No Absen/Kelas", "Skor", "Status", "Benar", "Salah"]);
  }
  sheet.appendRow([data.timestamp, data.name, data.studentNo, data.score, data.status, data.correct, data.wrong]);
  return ContentService.createTextOutput(JSON.stringify({result: "success"})).setMimeType(ContentService.MimeType.JSON);
}
